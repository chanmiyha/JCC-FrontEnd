This repository contains my undergraduate thesis project developed as part of the requirements for a Bachelor's degree in Informatics. (Back End part) 

Project: Export Handicraft Information 

System Description: 
A web-based information system designed to support export-oriented handicraft businesses in managing operational data efficiently. The system helps organize employee data, product information, supplier records, stock management, and transaction processing. It also provides important reports and invoices that can be accessed by the business owner. 

Tools: HTML, CSS, JavaScript, Laravel, Vue JS. 

Features: 
- Employee data management
- Product data management
- Supplier data management
- Stock management
- Transaction processing
- Transaction reports
- Stock reports
- Invoice generation accessible by the owner
